## Audit findings (P0–P3)

### Fixed this mission

- **P1** — Portfolio ledger concurrency: `post_transaction` did not lock the
  portfolio row; two concurrent buys could both pass the cash check. Now
  `SELECT … FOR UPDATE` serializes mutations. (13 ledger tests green.)
- **P1** — Alembic coverage gap: market/paper/watchlist tables existed only
  via `create_all`. Added autogenerated migration; `upgrade head` verified
  from an empty schema.
- **P2** — ECharts island bundle 1096KB → **532KB** (tree-shaken
  `echarts/core`: line/bar/scatter + grid/tooltip/legend + canvas renderer).
- **P2** — Legacy `apps/web` (Next.js) was still a workspace member and a
  second shipping app. Removed; `apps/web-astro` is the only frontend.
- **P2** — Widget registry doc drift after adding the historical-validation
  widget — `docs/WIDGET_REGISTRY.md` regenerated; drift test green.
- **P2** — New prefs system changed the built-in default country; reverted to
  preserve prior behavior (USA), user-configurable in Settings.
- **P3** — Lint hygiene in touched files (unused imports/vars); ~455
  pre-existing ruff findings remain across legacy `scripts/` — documented
  debt, not release-blocking.

### Open / deferred

- **P3** — Docker (optional path only) **not runtime-verified**: Docker
  Desktop's Linux engine never started on the dev host. Compose stack,
  Dockerfiles, entrypoint and nginx config are statically reviewed only.
  Native deployment is the supported path and is verified.
- **P3** — No authentication or rate limiting (documented; web port is
  loopback-bound by default, postgres is internal-only).
- **P3** — WID.world ingestion requires a manual 882MB bulk ZIP (opt-in
  `--wid-zip`), not part of scheduled collection.

## Features shipped this mission

- **Global search** — `GET /api/search` (countries/indicators/instruments/
  forces) + Ctrl/Cmd+K palette in the header.
- **Versioned preferences** — `bca:prefs` localStorage blob (theme,
  transparency, motion, default country/currency); pre-paint resolution via
  `window.__BCA_PREFS__`; full Settings panel rewrite; consumed by workspace
  defaults, StrategyLab and Portfolio currency.
- **Historical-validation workspace widget** — previously panel-only.
- **Dev-only component showcase** page.
- **Native deployment (primary)** — `serve.py`: one uvicorn process serves
  API + built Astro frontend same-origin on 127.0.0.1:8000. Windows
  launchers: Setup/Start/Start-Prod/Stop/Update/Backup/Restore/Test/Status
  .bat with dep/PG/config checks, health waits, duplicate-instance guard,
  pid-tracked stop (never kills unrelated processes), confirm-gated restore.
  Linux: `deploy/linux/` install.sh + hardened systemd unit + timers +
  nginx sample; docs in `docs/DEPLOYMENT.md`. Docker compose kept as an
  optional alternative.
- **Ops scripts** — `scripts/ops/` backup/restore/verify (ps1+sh), setup,
  dev, test; `apps/api/.env.example`; backups gitignored.
- **CI** — `.github/workflows/ci.yml`: backend pytest + frontend
  check/test/build on push/PR.
